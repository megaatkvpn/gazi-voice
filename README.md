# Gazi Voice ওয়েবসাইট — গাইড

## ফোল্ডারে কী আছে
```
index.html     ← পুরো সাইট
style.css      ← ডিজাইন
script.js      ← স্লাইডার, কাউন্টার, WhatsApp অর্ডার
images/
  banner1.jpg  banner2.jpg  banner3.jpg   ← উপরের (Hero) স্লাইডার
  banner4.jpg  banner5.jpg  banner6.jpg   ← "বিশেষ অফার" স্লাইডার
  logo1.png  logo.png  itel.png  silver.png
```

## ব্যানার কীভাবে বদলাবেন
1. ব্যানারের মাপ (যেকোনো মাপ দিলেও কাটবে না, পুরো ছবি দেখাবে; খালি জায়গা ঝাপসা ব্যাকগ্রাউন্ডে ভরে যাবে):
   - `banner1`–`banner3` (উপরের স্লাইডার): সবচেয়ে ভালো দেখায় **চারকোনা 1:1**, যেমন 1254 × 1254 px
   - `banner4`–`banner6` (অফার স্লাইডার): সবচেয়ে ভালো দেখায় **চওড়া 3:2**, যেমন 1536 × 1024 px
   - ছবি ৫০০ KB এর কম রাখুন, তাহলে সাইট দ্রুত খুলবে।
2. ছবির নাম অবশ্যই `banner1.jpg` … `banner6.jpg` হবে (ছোট হাতের অক্ষরে, `.jpg`)।
3. GitHub এ রিপোজিটরি → `images` ফোল্ডার → **Add file → Upload files** → নতুন ছবি দিন → **Commit changes**।
   একই নামের ফাইল দিলে পুরনোটা বদলে যাবে।
4. ১–২ মিনিট পরে সাইটে নতুন ব্যানার দেখাবে। না দেখালে ফোনে/ব্রাউজারে রিফ্রেশ করুন।
5. কোনো ব্যানার না চাইলে সেই ফাইল ডিলিট করে দিন — স্লাইডার নিজে থেকে বাকিগুলো দেখাবে।

## GitHub Pages এ অনলাইন করা (ফ্রি)
1. github.com এ অ্যাকাউন্ট খুলুন / লগইন করুন।
2. ডান উপরে **+ → New repository** → নাম দিন (যেমন `gazivoice`) → **Public** → **Create repository**।
3. **uploading an existing file** লিংকে ক্লিক করুন → এই ফোল্ডারের সব ফাইল (`index.html`, `style.css`, `script.js`, `images` ফোল্ডারসহ) টেনে ছেড়ে দিন → **Commit changes**।
   - মোবাইল থেকে ফোল্ডার আপলোড না হলে: আগে ৩টা ফাইল আপলোড করুন, তারপর **Add file → Create new file** এ নাম লিখুন `images/x` দিয়ে ফোল্ডার বানিয়ে ছবিগুলো আপলোড করুন।
4. রিপোজিটরি → **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**।
5. ১–২ মিনিট পর সাইট চালু হবে: `https://আপনার-ইউজারনেম.github.io/gazivoice/`

## নিজের ডোমেইন যুক্ত করা
### GitHub অংশ
1. **Settings → Pages → Custom domain** এ ডোমেইন লিখুন (যেমন `www.gazivoice.com`) → **Save**।
2. DNS ঠিক হওয়ার পর **Enforce HTTPS** টিক দিন (কয়েক ঘণ্টা পর অপশন আসতে পারে)।

### ডোমেইন প্যানেলের (যেখান থেকে ডোমেইন কিনেছেন) DNS অংশ
| Type  | Host / Name | Value |
|-------|-------------|-------|
| A     | @           | 185.199.108.153 |
| A     | @           | 185.199.109.153 |
| A     | @           | 185.199.110.153 |
| A     | @           | 185.199.111.153 |
| CNAME | www         | আপনার-ইউজারনেম.github.io |

- আগে থেকে থাকা পুরনো `@` এর A রেকর্ড বা `www` রেকর্ড মুছে দিন।
- `vsr` সাবডোমেইন (রিসেলার প্যানেল) এর রেকর্ড **মুছবেন না**।
- DNS কাজ করতে ১০ মিনিট থেকে ২৪ ঘণ্টা লাগতে পারে।

## অন্য কিছু বদলাতে
- **WhatsApp নাম্বার:** `script.js` এর প্রথম লাইনে `WHATSAPP_NUMBER`, আর `index.html` এ `wa.me/8801875884557` যেখানে যেখানে আছে।
- **প্যাকেজের মিনিট:** `index.html` এ `<li><span>…</span><b>… min</b></li>` লাইনগুলো।
- **কাউন্টারের সংখ্যা:** `index.html` এ `data-to="12000"` ইত্যাদি।
